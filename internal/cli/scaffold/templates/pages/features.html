Features

Four live demos. Each one is a few lines of Go and a template in this project.

API

The button posts to /api/count. The server answers with only the number, and JavaScript puts it on the page.

{{csrfToken}}

The count lives on the server and is shared by every visitor. Reload the page: it is rendered with the current number, because each click invalidates the cached page.

Forms

No JavaScript here. Pick a name and the server greets you on a page of its own.

This is a plain HTML form. It posts to /hello, the page's action reads the name, and the server renders a new page as the response.
