## 1. `collagetest.Site`: a real application for a plugin's tests

### Why not a fake Host

The phase 5 plan named `collagetest.Host`, a stand-in Host for unit-testing a
plugin's `Init`. Reading the 44 plugins' tests changed that: 75 test files
build a *real* application (`collage.New` with templates in an
`fstest.MapFS`, a home page, the plugin), drive it through `app.Handler()`,
and 28 of them write their own goroutine-safe log buffer. Six use
`collagetest`. A fake Host would let a plugin pass against something that is
not collage, and it would drift from the real Host with every release. The
helper plugins need is the boilerplate they already write, done once:

**Ruling:** no fake Host. `collagetest.Site` builds a real application with the
least configuration a plugin test needs and hands back the app, a `Client` on
it, and the captured logs. Cost if wrong: a later fake Host is still additive.

### API (in `pkg/collagetest`, new file `site.go`)

```go
// Site is a real collage application built for a test: the app, a Client on
// its handler, and everything it logged.
type Site struct {
	App *collage.App
	*Client
	Logs *Logs
}

// NewSite builds the application, starts it (plugins' Configure and Init run
// here, so their errors fail the test at once), and shuts it down when the
// test ends.
func NewSite(t testing.TB, options ...SiteOption) *Site

// TrySite is NewSite for a test that expects building or starting to fail:
// it returns the error instead of failing the test.
func TrySite(t testing.TB, options ...SiteOption) (*Site, error)

type SiteOption func(*siteConfig) // siteConfig is unexported

func WithPlugins(plugins ...collage.Plugin) SiteOption
// WithPluginConfig sets one plugin's section of the plugin configuration, as
// plugins-config.json would: WithPluginConfig("elagoht/robots", `{"disallow":["/admin"]}`).
// Invalid JSON fails the test.
func WithPluginConfig(name, json string) SiteOption
// WithTemplates adds or replaces templates by name ("layout.html": source).
func WithTemplates(files map[string]string) SiteOption
// WithRegister registers pages, documents and actions after the default home page.
func WithRegister(items ...collage.Registrable) SiteOption
// WithoutHome leaves out the default home page.
func WithoutHome() SiteOption
// WithConfig edits the configuration before New: locales, cache, BaseURL, dev mode, anything.
func WithConfig(edit func(*collage.Config)) SiteOption

// Logs is everything the application logged, at debug level and above, safe
// to read while the application runs.
type Logs struct{ /* unexported */ }
func (l *Logs) String() string
// Has reports whether a record at level or above contains every one of parts.
func (l *Logs) Has(level slog.Level, parts ...string) bool
```

### Defaults

- `Server: {Host: "localhost", Port: 3000}`; templates in an `fstest.MapFS`
  under root `t`: `layout.html` is
  `<!doctype html><html><head>{{hoist "head"}}</head><body>{{slot "content"}}</body></html>`
  and `home.html` is `<p>home</p>` — check the real slot/hoist template syntax
  in the scaffold and use what it uses.
- A page `home` at `/` (layout + content fragment) unless `WithoutHome`.
- The logger writes text records at debug level into `Logs`.
- No cache, not dev mode, no BaseURL, default locale only: a test opts in with
  `WithConfig`.
- `NewSite` calls `app.Start()`; `t.Cleanup` calls `app.Shutdown` with a 5 s
  context and reports a shutdown error with `t.Error`.
- The `Client` is `New(t, app.Handler())`, so `site.Get("/robots.txt")` and
  every existing `Client` method work on the site.

### Tests (`pkg/collagetest/site_test.go`)

- A plugin added with `WithPlugins` is initialised and serves a document; the
  home page answers 200.
- `WithPluginConfig` reaches `collage.PluginConfig` in the plugin's `Init`.
- `TrySite` returns a plugin's `Init` error; `NewSite` with the same plugin fails
  the test (use a fake `testing.TB` that records `Fatal`).
- `Logs.Has` finds a record the plugin logged at Warn; it is race-free under
  `-race` while the app serves concurrently.
- `WithoutHome` → `/` is 404; `WithRegister` pages are served; `WithTemplates`
  replaces `layout.html`.
- Shutdown runs at cleanup (a plugin's `Shutdown` is called).

## 2. Named kinds and stages

Untyped string constants in `pkg/collage`, so existing comparisons keep
compiling and the fields stay `string`. Each field's doc says the set may grow.

```go
const (
	RouteKindPage     = "page"
	RouteKindDocument = "document"
	RouteKindAction   = "action"
	RouteKindMount    = "mount"
	RouteKindHandler  = "handler"
)
const (
	BuiltPage     = "page"
	BuiltDocument = "document"
	BuiltAsset    = "asset"
)
const (
	StageRoute        = "route"
	StageGuard        = "guard"
	StageBeforeAction = "before_action"
	StageHandler      = "handler"
	StageBeforeRender = "before_render"
	StageRender       = "render"
	StageAfterRender  = "after_render"
	StageCacheWrite   = "cache_write"
	StageErrorPage    = "error_page"
	StageNotFound     = "not_found"
	StageAsset        = "asset"
	StagePlugin       = "plugin"
	StagePanic        = "panic"
)
```

The values must be exactly the strings the engine emits today (internal/core
`stage*` consts, internal/httpx route kinds, internal/build BuiltFile kinds);
define the internal ones from a single source so the public constants cannot
drift (e.g. pkg/collage's constants equal the internal ones, and a test asserts
every stage the engine can emit has a public constant).

Tests: a test that the public values equal the internal ones; a test that
RouteInfo(ctx).Kind == RouteKindDocument for a document request.

## 3. `DocumentBuilder.WithTimeout`

```go
// WithTimeout bounds the document's handler and render; zero (the default)
// means TemplateConfig.Timeout. A negative timeout records ErrInvalidTimeout.
func (b *DocumentBuilder) WithTimeout(d time.Duration) *DocumentBuilder
```

- `types.Document` gains `Timeout time.Duration`; `internal/render/document.go`
  uses it instead of the engine default when set (mirror `Fragment.Timeout` /
  `EffectiveTimeout`).
- It applies to live requests and static builds alike.
- `Document` is aliased, so its exported fields grow by one: additive.

Tests: a document whose handler outlasts its own short timeout fails with the
timeout error while `Template.Timeout` is long; one with a long own timeout
succeeds while `Template.Timeout` is short; negative records ErrInvalidTimeout.
