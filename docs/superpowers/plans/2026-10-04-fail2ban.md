# elagoht/fail2ban Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ban clients that probe or brute-force a collage site, with a shared, proxy-aware client address in the core and every early rejection visible to `RequestHook`.

**Architecture:**
- **Core (next minor: v0.46.0, or v0.47.0 if session collage-92's build-cache fix tags first):**
  - adds `ServerConfig.TrustedProxies` and `collage.ClientIP(r)`, with the trusted set carried in the request context;
  - moves the `RequestHook` bracket before the `%2f`/dirty-path rejections.
- **New repo `collage-fail2ban`** (stdlib only):
  - a bounded, clock-injected store of per-client, per-jail strikes and bans;
  - `finish(status)` judges each request (`probe` / `notfound`), and the app reports others;
  - a middleware answers banned clients with a plain 403.

**Tech Stack:** Go 1.26, stdlib (net/netip, net/http, sync), collage next minor.

**Spec:** `docs/superpowers/specs/2026-10-04-fail2ban-design.md`

## Global Constraints

- Never use the Go type `any` in new code.
- The core change is additive only: `TrustedProxies` empty means `ClientIP` is always `RemoteAddr`, and no existing behaviour changes beyond `RequestHook` now also seeing early rejections (CHANGELOG: a fix for observers).
- The plugin is stdlib only, besides github.com/Elagoht/collage. In memory, no goroutine of its own.
- Only `X-Forwarded-For` is read for the client; never `X-Real-IP` or `Forwarded`.
- A client is a prefix: /32 for IPv4, /64 for IPv6. The zero address is never counted or banned.
- Jail defaults:

  | Jail | MaxRetry | FindTime | BanTime |
  |---|---|---|---|
  | `probe` | 3 | 10m | 1h |
  | `notfound` | 50 | 1m | 10m |
  | other names | 5 | 10m | 15m |

- Other defaults: `MaxBanTime` 24h, `MaxTracked` 10000, `MaxBans` 10000.
- A repeat ban within 24h doubles, capped at `MaxBanTime`.
- Built-in probe prefixes (case-insensitive): `/.env`, `/.git/`, `/.aws/`, `/wp-login.php`, `/wp-admin`, `/xmlrpc.php`, `/phpmyadmin`, `/cgi-bin/`, `/vendor/phpunit`.
- Banned response: `403`, body `Forbidden\n`, `Content-Type: text/plain; charset=utf-8`, `Cache-Control: no-store`; the error page is never rendered.
- Plugin conventions:
  - module `github.com/Elagoht/collage-fail2ban` with a comment above `module`, `go 1.26`;
  - `const Name = "elagoht/fail2ban"`;
  - `New(opts)`; `Version()` "0.1.0";
  - README `# elagoht/fail2ban`;
  - `.gitignore` of `*.test` and `*.out`; no LICENSE.
- Plugin Init is lazy (`app.Start()`); Configure errors come from `collage.New`; middleware goes in through `host.Use` in Init.
- Core work happens in worktree `git worktree add -b feat/client-ip ../collage-clientip main`. The plugin builds through a go.work (`go work init ~/Desktop/collage-clientip ~/Desktop/collage-fail2ban` in a mktemp dir), and its go.mod requires collage v0.45.0 as a placeholder.
- Never `git add -A`. Commit trailer: `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`. Nothing is published inside tasks. Use `go test -count=1`.

## Review Focus

1. **A forged `X-Forwarded-For` from an untrusted client** must neither frame another address nor dodge a ban.
   - `TestClientIP` covers the forged-header rows (Task 1).
   - `TestE2E_ForgedXFFDoesNotDodge` covers the ban (Task 5).
2. **A distributed scan from 20,000 addresses:** memory stays within `MaxTracked` and `MaxBans`, and nothing panics. `TestStore_Bounds` (Task 4).
3. **Many concurrent strikes from one client at the threshold** produce exactly one ban and one `OnBan` call. `TestStore_ConcurrentOneBan` (Task 4) and `TestE2E_OnBanOnce` (Task 5).
4. **The ban's end boundary:** at `Until` the client is allowed again, and a moment before it is not. `TestStore_BanBoundary` (Task 4).
5. **`RemoteAddr` shapes:** `[::1]:8080`, `fe80::1%eth0` (zone), no port, garbage. Each gives the right address or the zero `Addr`; none panics. `TestClientIP` rows (Task 1).

- [ ] **Step 3: Implement.** `ClientIP`:

  ```go
  func ClientIP(r *http.Request) netip.Addr {
  	remote := parseAddr(r.RemoteAddr) // SplitHostPort, else the whole string; netip.ParseAddr; Unmap; WithZone("")
  	trusted, _ := r.Context().Value(trustedCtxKey{}).([]netip.Prefix)
  	if !remote.IsValid() || !contains(trusted, remote) {
  		return remote
  	}
  	client := remote
  	values := r.Header.Values("X-Forwarded-For")
  	for i := len(values) - 1; i >= 0; i-- {
  		parts := strings.Split(values[i], ",")
  		for j := len(parts) - 1; j >= 0; j-- {
  			a, err := netip.ParseAddr(strings.TrimSpace(parts[j]))
  			if err != nil {
  				return client
  			}
  			client = a.Unmap().WithZone("")
  			if !contains(trusted, client) {
  				return client
  			}
  		}
  	}
  	return client
  }
  ```

  Note the all-trusted case returns the leftmost, since `client` was last set to it.
