# elagoht/oauth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sign a reader in with any OpenID Connect provider, through elagoht/session, and let the application call the provider's APIs with sealed, auto-refreshed tokens. Also give the core an additive `collage.SafeRedirect`.

**Architecture:**
- **collage v0.44.0** exports the router's existing redirect check as `collage.SafeRedirect(next, fallback)`.
- **The new repo `collage-oauth`**, stdlib only:
  - registers `{prefix}/{name}/login` and `/callback` with `host.Handle`;
  - keeps the pending sign-in (state, nonce, PKCE verifier, next) in the session;
  - exchanges the code over TLS and checks the id_token's claims, without verifying its signature (OIDC 3.1.3.7);
  - maps the identity to the application's user through `OnLogin`, and signs in with `session.Regenerate` + `Set(UserKey, …)`;
  - seals tokens with AES-GCM for the application's `TokenStore`;
  - `Client` refreshes the token on demand, with in-process coalescing.

**Tech Stack:** Go 1.26, stdlib (crypto/aes, crypto/cipher, crypto/hmac, crypto/sha256, crypto/subtle, crypto/rand, encoding/json, net/http), collage v0.44.0, collage-session v0.2.1.

**Spec:** `docs/superpowers/specs/2026-10-04-oauth-design.md`

## Review Focus

1. **Login CSRF / session fixation:** the session ID must change at sign-in, so an attacker who planted a session before the reader signed in holds nothing afterwards. Test: `TestCallback_RegeneratesTheSession` (Task 5).
2. **Two tabs signing in at once:** the second login replaces the first's pending entry, so the first callback fails `state` rather than signing in with the wrong `next`. Test: `TestCallback_SecondLoginReplacesTheFirst` (Task 5).
3. **Callback with no session cookie at all** (cookies blocked, or a direct hit): it must fail `state`, never panic. Test: `TestCallback_NoPendingSignIn` (Task 5).
4. **A provider returning an id_token whose `aud` is an array without our client ID:** it must fail `token`. Test: a case in `TestCallback_ClaimChecks` (Task 5).
5. **`Client` called after `Revoke` from another goroutine:** it must not resurrect the token from the memory cache. Test: `TestRevoke_DropsTheCache` (Task 7).

```go
package collage

import "github.com/Elagoht/collage/internal/router"

// SafeRedirect returns next when it is a path on this site — it starts with "/",
// not with "//" or "/\", and holds no control character — and fallback
// otherwise; a fallback that is not one either gives "/". It is the check
// collage applies to its own redirects, for a login that sends the reader back
// to a "next" taken from the URL:
//
//	http.Redirect(w, r, collage.SafeRedirect(r.URL.Query().Get("next"), "/"), http.StatusSeeOther)
//
// An absolute URL is never accepted, even one on this site's own origin: the rule
// stays one simple check. collage itself still sends a guard's or an action's
// Location as given, since some must leave the site (a sign-in provider).
func SafeRedirect(next, fallback string) string {
	if _, unsafe := router.UnsafeRedirectReason(next); !unsafe {
		return next
	}
	if _, unsafe := router.UnsafeRedirectReason(fallback); !unsafe {
		return fallback
	}
	return "/"
}
```
