# Paginate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A library, `github.com/Elagoht/collage-paginate`, covering four things:
- pager arithmetic and a numbered window;
- path-paged links and static params, for export;
- query-paged links, for server-only listings;
- template-ready `Links`.

**Architecture:**
- `pager.go` holds the pure arithmetic: `New`, `Items`, `WithWindow`.
- `links.go` builds URLs: `Path`, `PathNamed`, `Query`, `Linker.For`.
- `params.go` holds `StaticParams`, `FromPath` and `FromQuery`.
- There is no plugin registration and no core change.

**Tech Stack:** Go 1.26, stdlib plus `github.com/Elagoht/collage` v0.57.0.

**Spec:** `docs/superpowers/specs/2026-10-08-paginate-design.md`

## Global Constraints

- **Types:** never use the type `any`. A type-parameter constraint `[T any]` is fine.
- **Module:**
  - path `github.com/Elagoht/collage-paginate`, `go 1.26`, with a comment above `module`;
  - README titled `# elagoht/paginate`;

  - no `collage.json`, no LICENSE, no `Plugin` type.
- **Version:** `const Version = "0.1.0"`, exported, so the docs can print it.
- **Defaults:** the window has `edges` 1 and `around` 2. `perPage < 1` panics with the message `"paginate: perPage must be at least 1"`.
- **`FromPath`:**
  - Accepts only the canonical decimal spelling of 2…`last`.
  - Everything else wraps `collage.ErrNotFound`: `fmt.Errorf("%w: page %q", collage.ErrNotFound, raw)`.
- **`FromQuery`:** any invalid or out-of-range value gives 1.
- **Tests:**

## Review Focus

1. **Page 1 must have exactly one URL.** `/blog/page/1` and `/blog/page/01` answer 404, and `Links` for page 1 point to `/blog`. Pinned in Task 2 by `TestApp_PageOneHasOneURL`.
2. **The last page can be short.** A total that is not a multiple of perPage gives the right `Limit` on the last page, and `Items` returns exactly the remainder. Pinned in Task 1 by `TestNew_LastPageShort`.
3. **Query links keep other parameters, in order.** `?q=go&sort=new&page=3` → page 4 keeps `q` and `sort`, in the same order. Pinned in Task 2 by `TestQuery_KeepsOthers`.
4. **Huge page numbers.** A path like `/blog/page/99999999999999999999` answers 404, not a panic or a 500. `New` with a huge `current` and `perPage` does not overflow `Offset`. Pinned in Task 1 by `TestNew_NoOverflow` and in Task 2 by `TestFromPath_Table`.
5. **A locale-prefixed site.** `PathNamed` gives `/tr/blog/page/2` under the `tr` locale. Pinned in Task 2 by `TestApp_PathNamedLocale`.

### Task 1: Repo, pager and window

**Files (new repo `~/Desktop/collage-paginate`, created with `git init`):**
- Create: `go.mod`:

```

// window, path-paged links a static export can write, and query-paged links.
//
// It requires collage the way any consumer does.
module github.com/Elagoht/collage-paginate

go 1.26

require github.com/Elagoht/collage v0.57.0
```

- Create: `pager.go`, `pager_test.go`, `.gitignore`, and `doc.go` with the package comment and `const Version = "0.1.0"`

**Interfaces:**
- Produces:

```go
type Pager struct {
	Current, Last, PerPage, Total int
	Offset, Limit                 int
	Prev, Next                    int
	Window                        []Slot
}
type Slot struct {
	N            int
	Gap, Current bool
}
func New(total, perPage, current int) Pager
func Items[T any](items []T, p Pager) []T
func (p Pager) WithWindow(edges, around int) Pager
```

**Behaviour:**
- **`New`:**
  - `perPage < 1` panics.
  - `total < 0` is treated as 0.
  - `Last = max(1, ceil(total/perPage))`, computed as `(total + perPage - 1) / perPage` with an overflow guard. If `total > maxInt - perPage`, compute `total/perPage + (1 if total%perPage != 0)`.
  - `Current` is clamped to `[1, Last]`.
  - `Offset = (Current-1)*PerPage`. It cannot overflow, because `(Last-1)*perPage <= total`.
  - `Limit = min(PerPage, Total-Offset)`, and never negative. When `Total` is 0, `Limit` is 0.
  - `Prev = Current-1` (0 if `Current == 1`) and `Next = Current+1` (0 if `Current == Last`).
  - `Window` comes from `WithWindow(1, 2)`.
- **`WithWindow(edges, around)`:**
  - Negative arguments are treated as 0.
  - Include page n if `n <= edges`, or `n > Last-edges`, or `|n-Current| <= around`.
  - Walk 1…Last in order.
  - Insert a `Slot{Gap: true}` only where consecutive included numbers differ by more than 1.
  - Mark `Current` with `Current: true`.
  - Never emit duplicates. Use a loop over n, not a set union, and do not build a slice of length Last for huge Last: iterate only the at most `2*edges + 2*around + 1` candidates in sorted order.
- **`Items`:**
  - If `p.Offset >= len(items)`, return `items[:0:0]`, which is empty and never nil.
  - Otherwise return `items[Offset : min(Offset+Limit, len(items))]`.

### Task 2: Links, params, app integration, README

**Files:**
- Create: `links.go`, `params.go`, `links_test.go`, `params_test.go`, `app_test.go`, `README.md`

**Interfaces:**
- Consumes: Task 1's `Pager` and `Slot`; `collage.ErrNotFound`; `(*collage.RenderContext).URL(name string, params map[string]string) (string, error)`; `rc.Request` for the query; `rc.PathParam`. Grep pkg/collage for how a handler reads a path parameter: `rc.Param(name)` or similar. Use whatever exists.
- Produces:

```go
type Linker struct{ /* unexported */ }
func Path(first, pattern string) Linker               // pattern contains "{n}"
func PathNamed(rc *collage.RenderContext, first, rest string) Linker
func Query(rc *collage.RenderContext, key string) Linker
func (l Linker) URL(n int) string
type LinkSlot struct {
	Slot
	URL string
}
type Links struct {
	Prev, Next string
	Window     []LinkSlot
}
func (l Linker) For(p Pager) Links
func StaticParams(count func(ctx context.Context, locale string) (int, error), perPage int) collage.StaticParamsFunc
func FromPath(rc *collage.RenderContext, param string, last int) (int, error)
func FromQuery(rc *collage.RenderContext, key string, last int) int
```

**Behaviour:**
- **`Path(first, pattern)`:**
  - `URL(1) = first`.
  - `URL(n) = strings.Replace(pattern, "{n}", strconv.Itoa(n), 1)`.
  - A pattern without `{n}` panics, because that is a programming error.
- **`PathNamed(rc, first, rest)`:**
  - `URL(1) = rc.URL(first, nil)` and `URL(n) = rc.URL(rest, {"n": n})`.
  - If `rc.URL` fails, the link is `""`. The error is not swallowed: return it from `For` through a logged warning instead. Choose one of these:
    - (a) make `Linker` hold the error and have `For` return `(Links, error)`;
    - (b) document that misnamed pages give empty links.

    Pick (a) for `PathNamed` only, and keep `For` returning just `Links`, by giving `PathNamed` a signature that returns `(Linker, error)`. It validates both names up front with `rc.URL` for n=1 and n=2.
- **`Query(rc, key)`:**
  - Parse `rc.Request.URL.RawQuery` into an ordered list of key/value pairs. Write a small parser: split on `&`, then on `=`, using `url.QueryUnescape` per part. Do not use `url.Values`, which does not keep order.
  - `URL(n)` sets the key's value to n, or removes the key when n == 1. Keep the first occurrence's position and drop any later duplicates of the key.
  - Re-encode with `url.QueryEscape`, then join to `rc.Request.URL.Path`.
  - When the result has no params left, the URL is the bare path.
- **`For(p)`:**
  - `Prev` = `URL(p.Prev)` if `p.Prev > 0`, else `""`. `Next` is built the same way.
  - `Window` copies each slot. Gap slots get an empty URL.
- **`StaticParams(count, perPage)`:**
  - Returns a function that calls count for the locale. On an error, it returns the error.
  - Otherwise it builds `Last` via `New(total, perPage, 1).Last` and returns `[]map[string]string{{"n":"2"}, …, {"n":strconv.Itoa(Last)}}`.
  - When `Last <= 1`, it returns an empty, non-nil slice.
- **`FromPath(rc, param, last)`:**
  - Read the raw param.
  - Valid only if it is non-empty, has only ASCII digits, has no leading `0`, has length ≤ 19, parses with `strconv.Atoi` without error, and is 2 ≤ n ≤ last.
  - Otherwise return the wrapped `ErrNotFound`.
- **`FromQuery(rc, key, last)`:**
  - Take the first value of the key.
  - Use the same digit rule but allow 1. On any failure, or outside 1..last, return 1.
